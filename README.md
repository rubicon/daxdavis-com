# daxdavis-com

Source for [daxdavis.com](https://daxdavis.com), the personal site of Dax Davis.

## Status

Repository infrastructure only. No framework has been chosen and no site source
exists yet. Framework selection, scaffolding, content, and deploy configuration
are tracked as their own issues.
