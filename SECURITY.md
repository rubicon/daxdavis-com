# Security Policy

## Supported versions

This repository holds the source for a single deployed website. Only the current
state of `main` is supported. There are no maintained older versions.

## Reporting a vulnerability

Report privately through GitHub's private vulnerability reporting:
https://github.com/rubicon/daxdavis-com/security/advisories/new

Please do not open a public issue for a security report.

Include what you found, how to reproduce it, and what an attacker could do with it.
Expect an acknowledgement within five business days.

## Scope

In scope: this repository's source, its build and deploy configuration, and the
behavior of the deployed site at daxdavis.com.

Out of scope: findings against third-party hosting, DNS, or CDN infrastructure,
which belong with those providers; and reports whose only content is automated
scanner output with no demonstrated impact.
